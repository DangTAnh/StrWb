## Spacing Scale

Declared values (must be multiples of 4 — all verified as multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline element gaps (e.g., label to input) |
| sm | 8px | Compact element spacing (e.g., form field margin-bottom) |
| md | 16px | Default element spacing (container padding, card padding) |
| lg | 24px | Section padding (page container, nav item spacing) |
| xl | 32px | Major layout gaps (page max-width padding) |
| 2xl | 48px | Major section breaks (footer margin) |
| 3xl | 64px | Not used in Phase 1 — reserved for catalog grid (Phase 3) |

**Exceptions:** Touch targets must be minimum 44px x 44px (Apple HIG / WCAG 2.1 AAA) for login button and nav links. Login form container is centered with max-width 360px and uses `md` (16px) internal padding.

**Source:** Default 8-point scale (multiples of 4/8). No upstream artifacts specify spacing tokens — Claude's Discretion per 01-CONTEXT.md §"Claude's Discretion".

## Interaction Contracts

### Authentication Flow

1. **Unauthenticated admin access** (D-15): User navigates to any `/admin/*` route while not logged in → redirect to `/login?next=/admin/...`
2. **Post-login redirect** (D-15): After successful login, redirect to `next` URL if present and safe (same-origin), otherwise redirect to `/admin` (dashboard)
3. **Logout** (D-13): `/logout` route, POST method (CSRF-safe), clears session, redirects to `/login` with flash "Bạn đã đăng xuất thành công"
4. **Session lifetime** (D-10): 30 days — `app.permanent_session_lifetime = timedelta(days=30)`
5. **Remember-me** (D-11): Always enabled — `login_user(user, remember=True)` on every login, no checkbox shown

### Redirect Safety

- `next` parameter: must start with `/` and not `//` (prevent open redirect / protocol-relative URLs)
- Invalid `next` → fall back to `/admin` dashboard

### Error Handling

- **Login failure** (D-12): Flash "Sai tên đăng nhập hoặc mật khẩu" (single message, no field-specific errors, no account lockout, no attempt counter per D-12)
- **404**: Generic Vietnamese message "Trang không tìm thấy" with link back to homepage
- **500**: Generic message "Đã có lỗi xảy ra, vui lòng thử lại" — no stack trace exposed (PLAT-02)

### Flash Messages

- Single flash zone per page, rendered above content
- Error messages: text color `#DC2626` (destructive)
- Success messages: text color `#059669` (green — success semantic, not in 60/30/10 palette but reserved for non-destructive success feedback)
