<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> app (all routes) | Untrusted input (cookies, form fields) crosses here; session cookie is the auth carrier |
| env -> app (config) | SECRET_KEY / admin credentials loaded from environment; secrecy assumed |
| app -> SQLite | Single-file DB; WAL + busy_timeout mitigate concurrent-write lock errors |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | Session forgery via missing/weak SECRET_KEY | mitigate | `create_app` raises `RuntimeError` when `SECRET_KEY` absent (PLAT-02); .env.example documents `secrets.token_hex(32)` generation; SECRET_KEY never committed |
| T-01-02 | Elevation of Privilege | Werkzeug debugger RCE if DEBUG=True in prod | mitigate | `DEBUG` read from `FLASK_DEBUG` env, default '0'; README states dev-only; production run uses waitress/gunicorn (Phase 4) |
| T-01-03 | Denial of Service | SQLite `database is locked` under concurrent writes | mitigate | `PRAGMA journal_mode=WAL` + `PRAGMA busy_timeout=30000` via `Engine` connect listener + `connect_args timeout=30` (PLAT-03) |
| T-01-04 | Spoofing | Weak/placeholder admin password | mitigate | init-db rejects `change-me` (D-04) and passwords < 8 chars (D-03) with click.ClickException |
| T-01-05 | Information Disclosure | Plaintext admin password storage | mitigate | Werkzeug `generate_password_hash` (scrypt) at insert/upsert (D-01); raw password never stored |
| T-01-SC | Tampering | Compromised pip packages | mitigate | RESEARCH.md Package Legitimacy Audit — all 6 packages [OK]/Approved, no postinstall scripts; any NEW package requires a blocking human checkpoint before install |
</threat_model>
