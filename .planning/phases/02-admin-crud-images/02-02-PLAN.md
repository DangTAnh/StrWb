    Magic-byte table (Pitfall 3):
    - JPEG: `b'\xff\xd8\xff'` at offset 0
    - PNG: `b'\x89PNG\r\n\x1a\n'` at offset 0
    - WebP: `b'RIFF'` at offset 0 AND `b'WEBP'` at offset 8
    - Map extension → matcher function (or bytes tuple), with `.jpg`/`.jpeg` both matching JPEG.

    Function `check_magic_bytes(ext: str, head: bytes) -> bool`:
    - return True if the first `head` bytes match the signature for `ext` per the table above; WebP checks `head[0:4] == b'RIFF' and head[8:12] == b'WEBP'`.

    Function `validate_image_upload(file_storage) -> tuple[bool, str]`:
    1. `filename = (file_storage.filename or '').strip()`; if empty → `(False, 'Không có file nào được chọn')`
    2. `ext = os.path.splitext(filename)[1].lower()`; if `ext not in ALLOWED_EXTENSIONS` → `(False, f'Định dạng không hợp lệ ({ext or "không xác định"}). Chỉ chấp nhận .jpg, .jpeg, .png, .webp')`
    3. `file_storage.stream.seek(0)`; `head = file_storage.stream.read(12)`; if not `check_magic_bytes(ext, head)` → `(False, 'File không phải ảnh hợp lệ (sai định dạng thực tế)')`
    4. `file_storage.stream.seek(0)`; try `Image.open(file_storage.stream)` then `img.verify()`; on any `Exception` → `(False, 'File ảnh bị hỏng hoặc không đọc được')` (Pitfall 3 step 3)
    5. re-open: `file_storage.stream.seek(0)`; `img = Image.open(file_storage.stream)`; `w, h = img.size`; if `w > MAX_DIMENSION or h > MAX_DIMENSION` → `(False, f'Ảnh quá lớn ({w}x{h}px). Tối đa {MAX_DIMENSION}x{MAX_DIMENSION}px')` (Pitfall 7 step 2)
    6. else `(True, '')`

    Do not use `werkzeug.utils.secure_filename` anywhere in this module (D-16 — it would strip Vietnamese characters; the display name comes from `original_filename`).
