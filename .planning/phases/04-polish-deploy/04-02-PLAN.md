<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet client -> nginx | TLS termination; rate-limited on /admin; only 80/443 open |
| nginx -> WSGI (127.0.0.1:8000) | waitress/gunicorn bind loopback; trusted proxy headers from nginx only |
| WSGI -> SQLite / uploads | reads app.db + static/uploads; SQLite WAL + busy_timeout (PLAT-03) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-D1 | Information Disclosure | SECRET_KEY | mitigate | Chỉ trong `.env`/systemd EnvironmentFile (không commit); `.env.example` chỉ placeholder; `create_app` fail-fast nếu thiếu (app/__init__.py:47-48). |
| T-04-D2 | Information Disclosure | debug mode | mitigate | `DEBUG=(FLASK_DEBUG=='1')`, default off; `.env.example` ghi `FLASK_DEBUG=0`; nginx chặn stack trace (proxy 500 thay vì expose). |
| T-04-D3 | Tampering / DoS | /admin brute force | mitigate | `limit_req_zone admin:10m rate=10r/m` + `limit_req zone=admin burst=5 nodelay`; app login Flask-Login đã có (D-04). Không basic auth / allowlist IP (theo user chọn). |
| T-04-D4 | Spoofing | X-Forwarded-Proto | mitigate | WSGI bind 127.0.0.1 chỉ nginx gọi được; nginx set header từ `$scheme` — header giả từ client ngoài không tới WSGI. Back-link scheme-agnostic (WR-03) không phụ thuộc header. |
| T-04-D5 | Tampering | static/uploads path traversal | mitigate | nginx `location /static/ { alias ... }` — chỉ serve dưới thư mục static; không proxy `..`; filename UUID (image_utils) không do client đặt. |
| T-04-D6 | Information Disclosure | TLS | mitigate | HTTPS bắt buộc (HTTP→HTTPS redirect), certbot auto-renew, HSTS `max-age=31536000; includeSubDomains`. |
| T-04-D7 | Elevation of Privilege | systemd/gunicorn | mitigate | Chạy User riêng (không root), `Restart=always`, bind loopback. |
</threat_model>
