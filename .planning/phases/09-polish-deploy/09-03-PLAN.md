From app/db.py `init_db_command` (what the docs must describe accurately):
- Requires `ADMIN_PASSWORD` env (>= 8 chars, not 'change-me'), else raises ClickException.
- `db.create_all()` creates missing tables only — never ALTERs an existing table.
- Migration guard (PLAT-05): PRAGMA `table_info(products)`; if `cost_price` absent -> `ALTER TABLE products ADD COLUMN cost_price INTEGER` (idempotent).
- Legacy orders guard: if an existing `orders` table has the old snapshot columns (`product_name`) and is EMPTY -> `DROP TABLE orders`, then the new schema is recreated; if it has ROWS -> raises ClickException 'Manual migration required: orders has legacy snapshot schema with data.' (never drops data).
- Upserts the admin account (create or reset password) from `.env`.
