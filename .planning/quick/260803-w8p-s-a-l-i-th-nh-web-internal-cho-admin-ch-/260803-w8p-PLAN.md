## Objective

Convert StoreWeb from a public-facing store into an internal web for admin. Rename "Cửa hàng" → "Quản lý hàng" across all user-visible templates, make the root `/` redirect to admin login for unauthenticated visitors (since this is now an internal admin tool), and reframe the Messenger contact strip as the order intake channel.

**As a** admin user, **I want to** see "Quản lý hàng" instead of "Cửa hàng" throughout the interface so that the label reflects this is now an internal product management tool, **so that** there's no confusion between the old public store concept and the new internal workflow.

## Context

- Root `/`, `/search`, `/products/<id>`, `/cart`, `/cart/*` and `/cart/checkout` are in `app/public.py` (public_bp blueprint)
- Admin routes are under `/admin/` (admin_bp), protected by `admin.py`'s `before_request` + Flask-Login
- "Cửa hàng" appears in: `public/_nav.html` (brand link), `public/base.html` (title + footer), `public/index.html` (title + empty-state body), `public/search.html` (title), `public/product_detail.html` (title), `errors/404.html` (title bar), `errors/500.html` (title bar)
- `MESSENGER_URL` config drives the contact strip in `index.html` line 28
- `404.html` and `500.html` use a ternary extends: `"public/base.html" if not admin/auth path else "base.html"`
