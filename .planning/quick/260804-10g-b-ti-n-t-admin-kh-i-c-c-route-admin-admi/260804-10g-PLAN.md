## Objective

Remove the `/admin` URL prefix from the admin routes so `/admin/products` → `/products`, `/admin/orders` → `/orders`, `/admin/stats` → `/stats`, then give every page persistent navigation: a header at the home page (`/`) with links to Sản phẩm / Đơn hàng / Thống kê, a Đăng xuất (logout) button, and on each admin page a navigation header that returns to `/`.

**Note — already done in the uncommitted working tree (verify, do not redo):** `app/admin.py` registration is `Blueprint('admin', __name__, url_prefix='')`; the old `/admin/` `dashboard` route (and `app/templates/admin/dashboard.html`) was deleted; `app/auth.py` login now redirects to `url_for('public.home')` instead of the deleted `admin.dashboard`. All templates reference admin pages exclusively via `url_for('admin.*')` / `url_for('public.home')`, so the prefix change needs NO link edits. The remaining work below is entirely header/nav templates + CSS.

## Context
- Blueprints registered in `app/__init__.py` (`public_bp`, `auth_bp`, `admin_bp`), no prefixes there — prefix comes from `admin_bp`.
- `app/templates/base.html` has an empty `{% block header %}{% endblock %}`. `app/templates/public/base.html` extends it and overrides the header with `{% include "public/_nav.html" %}`.
- Admin templates (`admin/orders/*`, `admin/products/*`, `admin/stats.html`) extend `"base.html"` directly → currently render with **no header**.
- `auth/login.html` extends `"base.html"` directly → must keep NO header (stays on root base.html).
- Logout is POST-only: `@auth_bp.route('/logout', methods=['POST'])`. CSRF token available in templates via `{{ csrf_token() }}` (same pattern already used in `admin/orders/detail.html`).
- Existing styles in `app/static/css/style.css`: `.site-header`, `.site-header__inner`, `.brand`, `.btn`, `.cart-link` — reuse these; add only `.site-nav` (and logout button tweak).
