# Quick Task 260824-n6i: Fix bug lọc đơn hàng AJAX

## Vấn đề

`loadFilteredOrders()` trong `app/templates/admin/orders/list.html:151` query
`.admin-card` nhưng wrapper bảng ở dòng 43 chỉ có class modifier
`admin-card--wide` (không có base `admin-card`) → `querySelector` trả null →
filter trạng thái AJAX không bao giờ chạy (chết im lặng từ trước redesign).

Phát hiện thêm cùng gốc rễ:

- Cả `list.html:43` lẫn `_content.html:1` thiếu base class `admin-card`
  (modifier không base → mất padding/nền/viền của `.admin-card`). Các trang
  khác (products/list, categories/list, stats) dùng đúng cặp
  `admin-card admin-card--wide`.
- `_content.html` trả về nguyên 1 card hoàn chỉnh (`<div class="admin-card--wide">…</div>`)
  trong khi JS gán vào `innerHTML` của container → nếu chỉ đổi selector sẽ bị
  card lồng card.

## Task 1: Sửa selector + cấu trúc partial + base class

**Files:**
- `app/templates/admin/orders/list.html`
- `app/templates/admin/orders/_content.html`

**Action:**
1. `list.html:43`: `<div class="admin-card--wide">` → `<div class="admin-card admin-card--wide" id="orders-table-card">` (base class cho đúng style + id để JS nhắm chính xác).
2. `_content.html`: bỏ wrapper `<div class="admin-card--wide">` mở/đóng, dedent nội dung còn lại 2 khoảng trắng → partial chỉ trả nội dung trong card (bảng + pagination / empty-state).
3. `list.html:151`: `document.querySelector('.admin-card')` → `document.getElementById('orders-table-card')`.

**Verify:**
- test_client: GET `/orders` (200, chứa `id="orders-table-card"`), GET
  `/orders?ajax=1&status=Đã gửi` với header X-Requested-With (200, KHÔNG chứa
  `admin-card--wide`, CHỨA `data-table` hoặc `empty-state`).
- grep: không còn `.admin-card')` dạng querySelector cũ trong list.html.

**Done:** Filter AJAX hoạt động; injected markup nhận đúng style card; không
card lồng card.
