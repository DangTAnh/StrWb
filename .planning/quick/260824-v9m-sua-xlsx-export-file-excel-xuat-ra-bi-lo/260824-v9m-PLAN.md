# Quick Task 260824-v9m: Sửa xlsx export — file Excel xuất ra bị lỗi

## Vấn đề

File tải từ `/orders/export.xlsx` mở bằng Excel báo "found a problem with some
content". Đã inspect XML của file build ra, xác minh 4 nhóm lỗi:

1. **File hỏng (lỗi chính):** `xl/theme/theme1.xml` chỉ chứa `<a:clrScheme>`,
   thiếu `<a:fontScheme>` + `<a:fmtScheme>` — vi phạm schema
   CT_ThemeElementSequence → Excel từ chối mở.
2. **Header sai:** đang copy từ `don-hang-gui-hang.xlsx` (tên cột bắt buộc bị
   che thành `"*"`). Phải dùng tên đầy đủ y hệt template gốc
   `collect_fee_mass_order_creation_template_vn_2level_addr.xlsx`, sheet
   "Tạo đơn (địa chỉ mới)", đủ **30 cột A..AD**.
3. **SĐT mất số 0 đầu:** heuristic `float()` biến mọi chuỗi số thành number —
   SĐT "0909999999" ghi thành `<v>909999999</v>`.
4. **Mapping sai nghĩa:** `allow_try` đang nhét vào cả cột S ("Giao hàng một
   phần") lẫn T ("Cho phép thử hàng"); AA "Hình thức thanh Toán" (bắt buộc *)
   bỏ trống; mã đơn chỉ điền dòng đầu trong khi template ví dụ lặp mã đơn trên
   MỌI dòng item của cùng đơn; sheet name "Đơn hàng" ≠ template gốc.

Route `export_orders_xlsx` trong `app/admin.py` (dòng 417-446) **KHÔNG đổi** —
giữ chữ ký `build_orders_xlsx(orders)` trả về `bytes`.

Executor sửa TRỰC TIẾP trên main working tree (không dùng worktree —
`app/xlsx_export.py` là file untracked WIP).

2. **BỎ heuristic `float()`** (đoạn try/except ở vòng ghi data rows). Thay bằng
   khai báo kiểu tường minh per-cột — định nghĩa set chỉ số cột NUMBER
   (0-indexed):

   - NUMBER (ghi `<c r=".."><v>{giá}</v></c>`): **A=0** (mã đơn), **K=10**
     (số lượng), **L=11** (giá tiền), **M=12** (cân nặng), **R=17** (giá trị
     đơn), **Y=24** (số tiền COD)
   - TEXT (ghi `t="inlineStr"`): mọi cột còn lại có giá trị (B, C, D, J, S, T,
     U, X, AA...)

3. **Sửa mapping dữ liệu** (chỉ số 0-indexed, `is_first` = dòng đầu của đơn):

   | Cột | Giá trị | Điền ở đâu |
   |-----|---------|------------|
   | A (0) | `seq` (số 1..n) | **MỌI dòng** item của đơn (theo sheet ví dụ mẫu — không phải chỉ dòng đầu như code cũ) |
   | B (1) | `order.customer_name` | dòng đầu |
   | C (2) | `order.customer_phone` | dòng đầu (TEXT — giữ nguyên "0…") |
   | D (3) | `order.customer_address` | dòng đầu |
   | E,F,G,H,I (4-8) | rỗng | web chỉ lưu địa chỉ text tự do, không tách 2 cấp |
   | J (9) | `item.product_name` | mọi dòng item |
   | K (10) | `item.quantity` | mọi dòng item (NUMBER) |
   | L (11) | `item.product_price` | mọi dòng item (NUMBER) |
   | M (12) | `order.total_weight` | mọi dòng (NUMBER) |
   | N,O,P,Q (13-16) | rỗng | — |
   | R (17) | tổng `product_price * quantity` các items | dòng đầu (NUMBER) |
   | S (18) | `"N"` cố định | dòng đầu (web không có khái niệm giao một phần) |
   | T (19) | `"Y"` nếu `order.allow_try` else `"N"` | dòng đầu |
   | U (20) | `"Y"` nếu `order.allow_view_only` else `"N"` | dòng đầu |
   | V,W (21-22) | rỗng | — |
   | X (23) | `"Y"` | dòng đầu |
   | Y (24) | tổng giá trị như R | dòng đầu (NUMBER) |
   | Z (25) | rỗng | — |
   | AA (26) | `"Người gửi trả"` | dòng đầu |
   | AB, AC, AD (27-29) | rỗng | — |

   Đơn không có item vẫn tạo 1 dòng (giữ logic `items = [None]` hiện có).

4. **Bỏ hẳn theme khỏi package** (fix lỗi mở file):
   - Xóa chuỗi `theme_xml` và dòng `zf.writestr("xl/theme/theme1.xml", ...)`.
   - `rels_xml`: chỉ còn worksheet (`rId1`) + styles (`rId2`) — xóa Relationship

   - `content_types`: xóa Override `/xl/theme/theme1.xml`.
   - Theme là optional part — workbook không cần nó.
