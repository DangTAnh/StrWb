# Quick Task 260824-wx4: Sửa nav bar tìm kiếm bản mobile (CSS + chức năng)

## Vấn đề (bản mobile <768px)

1. **Chức năng — "ấn nút Tìm không tìm mà chỉ ẩn thanh"**: trong `_nav.html`,
   `input.addEventListener('blur', ...)` gọi `closeSearch()` → form
   `display:none` ngay khi user chạm nút submit (touchstart gây blur trước
   click) → click không còn target → form KHÔNG submit.
2. **CSS — header mobile cao lởm chởm**: `.site-header__inner` column khiến
   nút "Tìm kiếm" (btn text to) chiếm nguyên hàng thứ 2 dưới logo/hamburger;
   khi mở, form xổ xuống đẩy cả trang.

## Hướng đã chốt với user

Header mobile **1 hàng**: hamburger + logo trái, icon tìm kiếm phải. Bấm icon
→ ô nhập trượt xuống NGAY DƯỚI header (absolute full-width). Desktop giữ
nguyên hiện trạng (form thường trực, toggle ẩn).

## Task 1: Sửa `_nav.html` (nút icon + JS đóng đúng)

**Files:** `app/templates/public/_nav.html`

1. Nút toggle: bỏ class `btn btn-primary`, nội dung text "Tìm kiếm" → SVG
   magnifier inline (stroke currentColor, ~20px), giữ class `search-toggle`
   cho JS/CSS. `aria-label="Mở tìm kiếm"`.
2. Script thay handler:
   - **BỎ** `input.addEventListener('blur', ...)` (gây bug submit).
   - Thêm đóng-khi-bấm-ra-ngoài: `document.addEventListener('click', ...)`
     — nếu `window.innerWidth < 768 && shell.classList.contains('is-open')
     && !shell.contains(e.target)` → closeSearch(). (Tap vào nút "Tìm" nằm
     trong shell → không đóng → submit chạy; submit xong handler
     `form.addEventListener('submit', closeSearch)` sẵn có tự đóng.)
   - Đổi aria-label theo state: mở → "Đóng tìm kiếm", đóng → "Mở tìm kiếm".
3. Giữ nguyên: toggle click is-open + focus input, submit-close.

## Task 2: Viết lại block mobile trong style.css

**Files:** `app/static/css/style.css`

Thay khối `@media (max-width: 767px)` hiện tại (dòng ~278-283) bằng:

```css
@media (max-width: 767px) {
  .site-header__inner {
    flex-direction: row;
    align-items: center;
    justify-content: space-between;
  }
  .mobile-search-shell { flex: 0 0 auto; }
  .search-toggle {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    width: 40px;
    height: 40px;
    padding: 0;
    background: transparent;
    border: 1px solid var(--color-border);
    border-radius: var(--radius-md);
    color: var(--color-text);
    cursor: pointer;
  }
  .search-toggle:hover {
    border-color: var(--color-accent);
    color: var(--color-accent);
  }
  /* Form neo vào .site-header (sticky = positioned): trượt ngay dưới header */
  .search-form {
    display: none;
    position: absolute;
    top: 100%;
    left: 0;
    right: 0;
    max-width: none;
    padding: var(--space-2) var(--space-4) var(--space-3);
    background: var(--color-surface);
    border-bottom: 1px solid var(--color-border);
    box-shadow: var(--shadow-md);
  }
  .mobile-search-shell.is-open .search-form { display: flex; }
}
```

Ghi chú:
- Bỏ rule cũ `.mobile-search-shell.is-open { flex: 1 0 100%; ... }` — form
  giờ absolute, không đẩy layout.
- Base `.search-form { display:flex }` (dòng ~258) vẫn thắng ở desktop vì
  override mới nằm trong media max-767 (sau base, cùng specificity).
- Desktop block `@media (min-width: 768px)` (dòng ~284-292) GIỮ NGUYÊN.
- Input đã có `flex: 1; min-width: 0` (dòng ~409) → tự chiếm hết form.
