# Quick Task 260825-01f: Export Excel chỉ lấy đơn "Đã gói"

## Yêu cầu user

File Excel gửi hàng chỉ chứa đơn trạng thái **"Đã gói"** (sẵn sàng giao
shipper). Hiện tại mặc định xuất cả "Đã gói + Đã gửi + Đã nhận", hoặc theo
`?status=` trên URL — gây trùng đơn khi tạo đơn hàng loạt trên hệ thống VC.

## Task 1: Route hard-code 'Đã gói'

**Files:** `app/admin.py` (route `export_orders_xlsx`, ~dòng 417-446)

Thay block:

```python
    requested = request.args.get('status', '').strip()
    # Mặc định: đơn đã gói trở đi (đã sẵn sàng giao cho shipper)
    allowed = ('Đã gói', 'Đã gửi', 'Đã nhận')
    if requested and requested in allowed:
        statuses = (requested,)
    else:
        statuses = allowed

    orders = (
        Order.query
        .filter(Order.status.in_(statuses))
```

bằng:

```python
    # EXPORT-02: chỉ xuất đơn đã gói — chưa tạo đơn trên hệ thống vận chuyển,
    # tránh trùng lặp khi upload file lên Viettel Post.
    orders = (
        Order.query
        .filter(Order.status == 'Đã gói')
```

Cập nhật docstring route ghi rõ "chỉ đơn Đã gói".
